## 两处问题

### 问题 1：腾讯被我判成「已退出」——这是判错

初版只查了腾讯智影的消费端 SPA 产品页，返回 404 就写了「已退出评估，不要再引用其价格」。

**事实**：腾讯有一条**在售的独立产品线**——腾讯云智能数智人（TCADH，`document/product/1240`），
《价格指南》最近更新 **2026-07-17**，售卖结构完整（形象采购 + 播报服务 + 交互服务，
需组合购买），配有视频生成服务 API、2D 定制 API、云渲染/端渲染 API+SDK。

已取到的价格（A 级，价格指南 2026-07-17）：

| 项 | 价格 |
|---|---|
| 2D 通用口型形象**租赁** | **50 元/个/月**（400 元/年） |
| 2D 专属口型形象**租赁** | **125 元/个/月**（1,000 元/年） |
| 2D 通用口型**定制**（5s 素材） | **2,500 元/个起**（阶梯至 200+ 个时 1,000 元） |
| 2D 专属口型**定制**（30s 素材） | **10,000 元/个起**（阶梯至 50+ 个时 3,000 元） |
| 2D 精品定制（影棚录制，1 天档期） | **350,000 元/个** |
| 视频播报合成小时包（免训练版） | 国际站公示 10 小时 4,500 美元（国内站价未取到） |

**为什么这条最有价值**：它的「免训练版」**不需要预先购买形象**——一段真人视频素材 +
文本/音频即出口型匹配的新视频。这是全部候选里**与现有 `avatar-spokesperson` 契约最贴合**
的形态（契约本来就是「character + voice + script → 一条口播视频」），
可省掉「形象采购/训练/审核」整套前置流程。新增 §6.3 专门展开。

代价：按小时包计费（单价高于训练版）；**产物只保留 7 天**，adapter 必须立即下载。

### 问题 2：飞影数字人整家漏了

已取到（A 级）：

- 个人版 **¥99/月**：1 形象席位 + **2 小时**生成时长 + 基础直播 → 折算 **≈¥0.83/分钟**
- 专业版 **¥399/月**：5 形象 + **无限**生成时长 + 高级交互
- 企业版定制：私有化部署 + **API 接入** + 专属客服
- 免费试用 3 天（带水印）
- **API V2 开放平台**（`api.hifly.cc`），Bearer Token，个人中心取 token
- 能力：一句描述/一张照片/一段视频 → 10 分钟出形象；5 秒视频克隆（正脸/侧脸/走动）；
  5–30 秒音频克隆；25 万+ 创作者与企业

**必须写的误读警示**（新增 §6.4）：¥99/月 的个人版**不含 API** —— API 挂企业版。
按 ¥99 做预算、到商务环节发现不是这个数，是这类厂商最常见的踩坑。

## 由此产生的方法论修正

### §5.4 交叉校验从「3–5 倍」改为「12 倍」，并解释这 12 倍的本质

加入飞影 ¥0.83/分钟（¥99 ÷ 120 分钟）后，同一条「1 分钟口播视频」的价格带变成：

| 口径 | 数值 |
|---|---|
| 飞影个人版折算 | **¥0.83/分钟** |
| 蝉镜订阅折算 | ¥2.0/分钟 |
| 华为云 6,000 分钟包 | ¥4/分钟 |
| 华为云 60 分钟包 | ¥8/分钟 |
| 阿里云按量 | ¥9.9/分钟 |
| 华为云按量 | ¥10/分钟 |

新增第 5 条差异来源：**这 12 倍不是「同一件商品的市场波动」，而是两类商品**——
创作者工具包（¥0.83–2.1）vs 企业推理服务（¥4–10）。
**正确读法是先决定买哪一类，再在类内比价**；跨类比价只会得出「最便宜的也是最好的」这个错误结论。

### §4.4 从「已退出」改写成「一处已纠正的漏检」

新增判据：**「产品页 404」≠「厂商退出」**。大厂常见「消费端 SPA 下线、企业端云产品在售」的
分裂形态。可靠信号是查云厂商产品文档目录（`document/product/<id>`）与**价格页的
「最近更新时间」**——长期不更新的价格页通常意味着产品停滞。

### 本轮最重要的发现：腾讯阶梯价击穿了「2D 定制窄带」

前几轮一直写「2D 真人定制稳定在 **5,000–8,000 元/个**的窄带（三家互证）」。
腾讯的价格指南推翻了「稳定」这个判断：

| 档位 | 单价 |
|---|---|
| 2D 通用口型定制（5s 素材） | **2,500 元/个起** |
| 20–80 个 | 2,000 元/个 |
| 80–200 个 | 1,200 元/个 |
| **200 个以上** | **1,000 元/个** |

⇒ 「5,000–8,000 窄带」只适用于**单件定制**。**批量采购时单价可降到 1/5**。
选型时最容易被忽略的维度：要做「一批形象」（IP 矩阵、多账号运营）而非「一个形象」时，
成本结构完全不同。已在报告 §5.3 写明。
