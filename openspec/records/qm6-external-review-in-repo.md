# QM-6 高危复核的"已被外部解除"判定搬进仓内

高危域阻断能否被真外部复核解除，原先只由仓外评审引擎的一份未版本化本地副本决定；
那份副本 2026-10-24 被换掉，能力当场消失，而仓内没有任何断言因此变红。
现在这段判定住在 `scripts/lib/ccg-external-review-honor.js`（零依赖纯函数），
写回器与 `check-pr-exec-record.js` 共用它，走了这条路的记录以 `tierBasis="adjudicated-self-play-honored"`
在覆盖率与水位读数里单独成第三档（`a+b+c == external` 由锁钉住，采样域同步扩到派生态）。
主干该形态适用人群实测为 0 条，因此本刀不把任何一次既有的"拦"变成"放"，
只是让未来的自扮演轮次在真外部复核到位时机制上可签，不必再手写 `tier`。
