# Change: createview-config-profile-extract

## Why

`apps/desktop/src/views/CreateView.vue` 现 **5563 行**（里程碑 2 收口时 4896 行，净 +667），
被仓内门禁 `check-max-lines` 的 `targets` **零容差**点名（目标 5656 行 ⇒ **余量仅 93 行**）。

仓内定案文档 `01-docs/FRONTEND-FILE-SPLIT-PLAN-2026-10.md` §2.9（2026-10-10）以实测数据判定
**第 5 步（useS2vConfig + ConfigProfile）不做**，依据有两条：① 成本最高（`s2vConfig 108 + Profile 174` 触点）；
② 收益不足（冲突频率 7/50，与已拆的 TTS 域 8/50 相当，「压力已分摊」）。

**2026-10-25 复评表明：依据 ② 的前提已变。**

| 判据 | 2026-10-10 基线 | 2026-10-25 实测 | 变化 |
|---|---|---|---|
| ConfigProfile 冲突频率 | 7/50（含 s2vConfig，14%） | **1/50（2%）** | **−86%** |
| ConfigProfile 相对触点 | 全案最重之一 | 与**已拆**的批量创作同量级 | 显著下降 |
| `useS2vConfig` 相对触点 | 108 | **最重的未抽域** | 上升 ⇒ **仍不做** |
| QuickRender 冲突频率 | 2/50 | **0/50** | ⇒ 仍不做 |

⇒ **ConfigProfile 重新成为候选**；`useS2vConfig` 与 QuickRender **维持不做**。

⚠️ **本 change 的范围只到「规格定案」**：它交付**第一刀的可执行规格**（范围、状态处置、执行纪律、
数据校验、流程、提示文字落点、验收判据），**不包含实现**。
⇒ 原因：仓内定案 §五-3 要求拆分落地后跑 **QM-4 像素回归**（`npm run test:visual:pixel`），
该验证需 Electron + 浏览器环境，**不在本变更的执行环境内** ⇒ 实现必须与像素回归在同批完成，
否则等于把「未验证的重构」先合入主干。

## What Changes

- 新增 `01-docs/PRD-CREATEVIEW-SPLIT-REVIEW-2026-10-25.md`：**复评报告 + 第一刀定案**
  （含数据校验、流程、交互、显示项、提示文字、风险清单、验收判据、与既有文档的关系）。
- 在仓内定案文档 `01-docs/FRONTEND-FILE-SPLIT-PLAN-2026-10.md` 加一节指针，指向本复评，
  **不改其既有结论性内容**（目标结构 / 拆分顺序 / 红线 / 浮层合同 / 执行纪律继续有效）。
- 本 change **不新增任何运行时代码**，不触碰 `CreateView.vue`、不触碰 `locales/`。

## Impact

- **治理面**：纯文档（PRD + openspec 规格 + 指针）⇒ 走 docs-only 快速通道；不碰 `CHANGELOG.md`。
- **运行时**：**零影响**（无代码变更 ⇒ 无像素回归风险、无测试回归风险）。
- **对后续**：第一刀实现将由**后续 change** 执行（见 design.md「后续 change 预告」），
  其规格已在本 PRD §4 定死，避免实现阶段重新争论范围。
- **纪律**：`openspec-sync-check` 要求 **active change 的 tasks 无未完成项**
  ⇒ 本 change 的 tasks 只列**本轮实际完成**的项并全部勾选；实现项**不进本 change 的 tasks**
  （不勾未做的事，也不把未做的事伪装成已完成）。

## 复评的诚实边界

- **触点口径与定案文档不同源**（本次 = 「域标识符全文出现次数」；定案 = 另一口径，
  同域差 6.5 倍）⇒ **只做同次测量内的相对排序**，**不与 108/174 直接对比**。
- **冲突频率口径同源可比**（同为「近 50 次改动的域命中率」）⇒ **它是本次复评的主证据**。
- **28/50 的 commit 未归类到任何域** ⇒ 命中率是**下界**（域归组靠方法名匹配，
  纯模板/纯 CSS 改动不计）⇒ 域间**相对**排序仍可用，绝对值偏低。
- **数字人域 5/50（10%）是当前高频域**，但它**已被拆**（`useAvatarCatalog` 138 行 +
  `useAvatarClone` 398 行）⇒ CreateView 侧剩余的是**桥接层** ⇒ **不是候选**。
