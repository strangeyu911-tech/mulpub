## 四、顺带修掉的一个真缺陷（由 M5 追出来的）

`isCollectDue` 原本用 `(now - last) >= interval` ⇒ **时钟回拨**（系统时间被改 / 记录写错）时恒假
⇒ 该平台**永远不再采集**，而界面上看不出任何异常（只是数字不再更新）。
⇒ 改为：`now <= last` ⇒ 允许采集（重新采一次是安全侧），并加了一条区分性用例（M6 证明有牙齿）。

## learnings

### lesson: 叶子模块的单测全绿**不等于**接线 —— 接线必须由调用方的 e2e 锁

**现场**：新增 `collector-contract.js`（纯函数）后 27 例全绿，但那一刻它**没有任何调用方**
——契约层能加载、能判定，却没有任何生产路径调用它。

**根因**：这类「判据 / 契约 / 纯函数」模块天然长得像叶子模块，而叶子模块的单测只证明
**它自己正确**，不证明**有人用它**。

**可复用的 3 条**：

1. **新增叶子模块的同一个 PR 里必须有调用方的 e2e**（本次 7 例：注入执行体 ⇒ 真走新路径；
   裸对象 / 未就绪 / 字段缺失 / 平台不符 / 未注入 / 执行体抛错 ⇒ 落 error 且**零数值字段**）。
2. **接线锁要锁「接线」，不是「实现」** ⇒ 断言落在**调用方**的输出上（结果含/不含某字段），
   而不是重复断言契约层自己。
3. ⚠ **「未接线」的中间态必须显式登记** ⇒ 本片把「执行体 / 新式脚本 / 账号选择」三件未做的事
   逐条写进执行记录，否则下一个人会以为「契约层接上了 ⇒ 粉丝数该出来了」。

### lesson: 恒真的断言要**标出来**，否则后人会以为它有牙齿

**现场**：变异验证里两条断言在任意合理实现下都成立（最小间隔为 0 ⇒ 恒可采集；负数间隔同理）
⇒ 变异打它们不红。若不查，就会误判成「锁没牙齿」并去改实现。

**根因**：`(now - last) >= 0` 在 `now >= last` 时恒真 ⇒ 「间隔为 0 ⇒ 恒可采集」这条**没有区分力**。

**可复用的 3 条**：

1. **变异不红时先问「这条断言有没有区分力」**，再问「锁有没有牙齿」。
2. **恒真断言要在用例名上写明「不变量断言，不参与变异验证」** ⇒ 避免后人误用。
3. ⭐ **找区分输入的通用手法**：找一个让两种实现**必然给出不同结论**的输入
   （本次：时钟回拨 `now < last` ⇒ 「提前返回」与「`(now-last) >= interval`」结论相反）。
   ⇒ 顺带发现一个**真缺陷**（时钟回拨 ⇒ 永久不采集 ⇒ 数字静默不再更新）。
