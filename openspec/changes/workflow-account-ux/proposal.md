# Proposal: 账号选择体验（P1-8）

## Why

账号多时，发布账号区只有一长串复选框：找账号靠肉眼、选多个账号靠逐个点、最近用过的账号每次都要重新找。账号是发布单元，选择体验直接影响自动化任务配置效率与错误率。

## What Changes

- `WorkflowEditor` 发布账号区新增：
  - 搜索框（账号名称 / 平台 / 备注 / 状态 / ID，大小写不敏感）；
  - 「全选当前结果」只选当前过滤后可用账号；
  - 「清空已选」；
  - 健康状态汇总「可用 N · 不可用 M」；
  - 「最近使用」账号 chips（localStorage 持久化最近 10 个，展示最近 5 个可用账号）。
- 分组仍按平台；搜索无结果时显示「没有匹配的账号」，不是空白。
- 过期/未启用账号仍不可勾选；全选跳过不可用账号。

## Non-goals

- 不做账号虚拟列表（P2-19）；当前先解决搜索/批量/最近使用。
- 不做跨设备最近使用同步；localStorage 仅本机。
- 不改变账号状态判定与发布前预检。

## Impact

- 纯渲染层改动，不涉及发布链路。
- localStorage 只存账号 ID，不存凭证；隐私模式写入失败静默降级。
- 账号列表为空时仍走原空态。
